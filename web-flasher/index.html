C3AdBlock

ESP32-C3 DevKit · 4 MB

A Pi-hole-style DNS ad blocker that fits in your pocket — flashed straight from this page, no software install.

Browser Flasher

Flash your ESP32-C3

Plug the board in over USB, connect below, and install. The browser erases the chip and writes the bootloader, partition table, firmware, and a ~112,000-domain blocklist.

Your browser doesn't support Web Serial. Use desktop Chrome, Edge, or Firefox. You can only use this tool over HTTPS in a browser window.

Port not showing up? Hold the board's BOOT button (GPIO9) while you plug it in (or while pressing RST) and keep holding until you click Connect — that forces the C3's ROM download mode.

First boot

1
Watch the logs

In the dialog after flashing, click Logs / Visit console and select the board's port again. Press the board's RST button once — the device reboots and prints its dashboard password. Look for [cfg] dashboard password: and write it down.

2
Join the setup hotspot

The board starts a Wi-Fi AP named C3AdBlock-Setup, protected by the same password printed in the logs in step 1. Connect to it from your phone or laptop and open http://192.168.4.1 — the captive portal should pop up.

3
Enter your Wi-Fi

Type your network name and password, click Connect, and the board reboots onto your network.

4
Open the dashboard

Go to http://c3adblock.local (or the IP shown in the logs). Username admin plus the password from step 1 gets you in.

5
Point your network at it

Reserve an IP for the board in your router, then set your router's DHCP DNS server to that IP. Skip a secondary DNS — a fallback resolver lets clients bypass the filtering. Test with one device first: set its DNS to the board's IP and check that ads stop resolving.

What gets written

PartOffsetSize
Bootloader (ESP32-C3)0x013 KB
Partition table (dual OTA + LittleFS)0x80003 KB
OTA data init0xe0008 KB
Ad-blocker firmware0x100001.1 MB
Blocklist filesystem (~112k domains)0x2b00001.4 MB

Blocklist = StevenBlack hosts + Hagezi Light. Blocked domains are answered with 0.0.0.0 / ::; the device answers DNS on both UDP and TCP, and everything else is forwarded upstream. Firmware and blocklist updates happen over Wi-Fi from the dashboard after the first flash.

Troubleshooting

Browser not supported

Web Serial needs a desktop Chromium browser — Chrome, Edge, Opera, or Brave on Windows/macOS/Linux. Not Safari, not iOS/Android. Firefox 151+ works too, but it asks you to install a site-permission add-on the first time — Chrome or Edge is the smoothest path.

Port never appears

Use a data-capable USB cable (charge-only cables are the #1 cause). If the board is stuck running app firmware, hold BOOT while plugging it in or while pressing RST to force download mode, then click Connect. After flashing completes, press RST once to boot the new firmware.

Linux permission denied

Add a udev rule: echo 'SUBSYSTEM=="tty", ATTRS{idVendor}=="303a", MODE="0666"' | sudo tee /etc/udev/rules.d/99-esp.rules then reload rules with sudo udevadm control --reload-rules. On Fedora/Ubuntu, ModemManager can also grab the port — sudo systemctl stop ModemManager while flashing.

"This chip is not compatible"

This flasher is built for the ESP32-C3. A board with a different chip (like an ESP32-S2 or classic ESP32) will be rejected — each chip family needs its own flasher build.

Prefer the terminal?

# one file, everything included — flash to 0x0
esptool.py --chip esp32c3 --port /dev/ttyACM0 --baud 460800 \
  write_flash 0x0 full-flash-r5.bin

# then test it once it's on your network
$ dig @<c3-ip> doubleclick.net  # → 0.0.0.0 (blocked)
$ dig @<c3-ip> github.com        # → real IP (forwarded)

Grab full-flash-r5.bin (4 MB merged image), or the individual bootloader, partitions, OTA-data init, firmware, and blocklist images.
